# yammy723

This repository is used to keep the project files and AI working context in sync across computers.

## How to Continue on Another Computer

1. Clone or pull this repository.
2. Open the repository folder in Codex.
3. Read `AGENTS.md` and `PROJECT_NOTES.md` before continuing work.
4. After making changes, commit and push them back to GitHub.

## Common Git Commands

```powershell
git status
git add .
git commit -m "Update project notes"
git push
git pull
```
