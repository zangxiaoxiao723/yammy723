# HPDI咚声响度量化说明

指标口径：45-650 Hz低中频冲击带，事件窗口扣除前后局部背景，尽量排除台架稳态嗡声；高频排气尖声仅作为污染筛选，不参与咚声响度计算。
同一手机、同一位置下，dBFS可用于相对比较。数值越低代表咚声越小；富瑞-东德差值大于0代表富瑞更响。

## 匹配转速差值
- 700 rpm: P50差值 -3.19 dB, P90差值 2.82 dB, P95差值 3.94 dB
- 800 rpm: P50差值 1.90 dB, P90差值 0.04 dB, P95差值 -0.36 dB
- 900 rpm: P50差值 2.53 dB, P90差值 5.83 dB, P95差值 3.39 dB
- 1125 rpm: P50差值 25.89 dB, P90差值 2.20 dB, P95差值 2.11 dB
