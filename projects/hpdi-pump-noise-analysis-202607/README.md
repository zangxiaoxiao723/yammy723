## 用户目标

以东德竞品为暂定基准，量化富瑞 HPDI 低温泵的泵本体咚声。后续每轮调试都要回答：

- 相同转速下，富瑞常见咚声比东德高还是低。
- 偏响周期是否改善。
- 超过东德较响门槛的周期占比是否下降。
- 结果是否有足够方法一致性和试验重复性。

## 客户口径

- `常见咚声`：有效事件中间位置，代表多数正常周期。
- `较响咚声`：偏响的约 10% 事件，代表更容易被客户注意的冲击。
- `超过东德较响门槛的比例`：富瑞事件超过同转速东德较响门槛的占比。
- 客户可见主结果继续使用V2固定口径的正数估算dB(A)。背景对齐结果只能称为“咚声突出度辅助指标”，不得覆盖主结果。
- 正式结论只比较相同转速。不同转速可以看趋势，不能直接判定产品优劣。

## 干扰排除

- 泵咚声通道：45-650 Hz。
- 排气污染监测通道：1800-9000 Hz。
- 每个事件扣除前后局部背景功率，降低台架稳态嗡声影响。
- 高频排气占优的事件不进入咚声统计。
- 80 ms 短时 RMS、20 ms 步长形成整体包络。
- 禁止用逐段背景平移修改既定基准。无分贝仪的跨日期结果必须标记手机自动增益风险。

算法只能降低干扰，不能证明单通道手机录音已经百分之百分离所有声源。

## 方法验证结论

已使用未计权、A计权和三个分频段共 5 种方法，对 700/800/900/1125 rpm 做事件重采样验证。

- 900 rpm 较响咚声：5种方法均支持富瑞偏响，当前证据最强。
- 1125 rpm 较响咚声：4种支持富瑞偏响，1种无法区分。
- 800 rpm 常见咚声：4种支持富瑞较低，1种无法区分；较响咚声不能定论。
- 700 rpm：当前单段录音不足以证明谁更好。

当前仍缺每个工况至少 3 次独立重复，因此结果用于工程比较，不替代认证声级测试。
