# HPDI低温泵咚声响度量化项目

## 项目目的

本项目用于比较东德竞品低温泵与富瑞自研HPDI低温泵的泵本体“咚声”响度，并为后续调泵建立可复跑的量化指标。

用户真正关心的问题不是“咚几声”，而是：

- 富瑞自研泵的咚声是否比竞品更大。
- 后续调整后，能否用数据证明富瑞已经不比竞品响，最好比竞品更小。
- 分析时要尽量排除台架嗡声和尖锐排气声等环境干扰。

## 当前基准结论

当前初始状态下，富瑞自研泵在多个匹配转速的较响咚声指标上高于东德竞品。

重点看P90/P95，而不是只看P50：

- P50：典型咚声。
- P90/P95：较响、较突兀的咚声，更接近人耳主观觉得“吵”的部分。

匹配转速下的关键差值为“富瑞 - 东德”，正值表示富瑞更响：

| 转速 | P50差值 | P90差值 | P95差值 | 判断 |
|---|---:|---:|---:|---|
| 700 rpm | -3.19 dB | +2.82 dB | +3.94 dB | 富瑞偶发重击偏响 |
| 800 rpm | +1.90 dB | +0.04 dB | -0.36 dB | 基本接近竞品 |
| 900 rpm | +2.53 dB | +5.83 dB | +3.39 dB | 富瑞明显偏响，优先优化 |
| 1125 rpm | +25.89 dB | +2.20 dB | +2.11 dB | P90/P95偏响，P50异常需谨慎 |

后续调试建议判定目标：

- `富瑞 - 竞品 <= 0 dB`：不比竞品响，可认为达到竞品水平。
- `富瑞 - 竞品 <= -2 dB`：有较明确优势，建议作为优化目标。
- 如果只降低P50但P90/P95仍高，主观听感可能仍会觉得冲击大。

## 干扰声处理口径

算法没有直接使用全频总声压，而是在45-650 Hz低中频冲击带内检测泵往复运动的咚声事件。

处理思路：

- 每个咚声事件用前后局部背景扣除，削弱台架稳定嗡声。
- 1800-9000 Hz高频带主要作为排气尖声污染检查，不进入咚声主响度指标。
- 同一手机、同一位置、同一录音方式下，dBFS可用于相对比较；该指标不是声级计绝对dB(A)认证值。

## 后续继续分析时的优先级

1. 对新测试数据按相同口径复跑P90/P95指标。
2. 用`matched_speed_comparison.csv`同格式输出“新状态富瑞 - 初始富瑞”和“新状态富瑞 - 东德竞品”。
3. 判断改善时优先看P90/P95是否下降，而不是只看总声压或P50。
4. 如果出现油压偶发170 bar，应同步观察液压压力、油缸位移、出口压力和咚声峰值，看是否与卡滞/换向卸压/低温端阀动作异常相关。
